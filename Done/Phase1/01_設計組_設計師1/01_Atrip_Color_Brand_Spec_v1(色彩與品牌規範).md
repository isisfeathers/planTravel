# Atrip 色彩規範 v1.1

工單：TRACK0-01｜品牌設計系統與 Design Tokens

適用範圍：Atrip 介面色彩、偏好標籤配色與文字對比。

## 1. 核心色彩

以下為色彩的設計語意名稱，Figma 樣式與前端 Tokens 使用一致的色值及用途。

| Token | 色碼 | 用途 |
|---|---|---|
| action.primary | #B9E85A | 開始規劃、下一步等主要按鈕背景 |
| action.on-primary | #182B36 | 亮綠按鈕的文字及圖示；不使用白字 |
| action.primary-hover | #ACDD4D | 主要按鈕 Hover 背景 |
| surface.page | #FFFDFA | 暖白頁面底色 |
| surface.card | #FFFFFF | Header、卡片、輸入欄位、底部導覽 |
| surface.subtle | #F3F5EF | 次要提示區塊底色 |
| text.primary | #182B36 | 標題、內文主要文字 |
| text.secondary | #52616B | 輔助說明及次要資訊 |
| border.subtle | #E4E8E0 | 裝飾性分隔與卡片輪廓；不作唯一操作邊界 |
| selection.background | #EFF8DA | 已選項目／當前導覽的柔和底色 |
| selection.foreground | #416519 | 已選文字、勾選與邊框 |
| brand.logo-ai | #277E99 | Logo 中 A、i 及航線，純色無漸層 |
| brand.logo-trp | #182B36 | Logo 中 t、r、p |
| focus.ring | #277E99 | 鍵盤焦點提示 |

主要按鈕採亮綠底、深墨色字。Logo 的 A、i（含圓點）與航線採純色藍青色，t、r、p 採深墨色。亮綠不作白底小字使用。

## 2. 偏好標籤分類色

| 類別 | 背景 | 文字／線性圖示 |
|---|---|---|
| 咖啡 | #F0ECE3 | #6B604B |
| 自然 | #EBF1E8 | #446345 |
| 在地美食 | #F2ECE5 | #72604F |
| 慢慢走 | #F0EFEB | #5D625B |
| 文化 | #EAE8F0 | #56566C |
| 攝影 | #EAF1F3 | #3E6373 |

分類色用於偏好標籤底色。選中時保留分類底色，以 #416519 邊框及勾選標記共同提示。分類名稱為視覺配色對應，不新增或變更偏好資料欄位。

一般資訊標籤採 #F0F2EC 底、#52616B 字。

| #182B36 | #FFFFFF | 14.61:1 | 通過 |
| #52616B | #FFFDFA | 6.30:1 | 通過 |
| #277E99 | #FFFFFF | 4.64:1 | 通過 |
| #416519 | #EFF8DA | 6.16:1 | 通過 |
| #6B604B | #F0ECE3 | 5.24:1 | 通過 |
