# Atrip 字體與版面規範 v1.1

工單：TRACK0-01｜品牌設計系統與 Design Tokens

適用範圍：LIFF 手機介面的字體、間距、圓角、陰影與共用尺寸。色彩搭配依 `01_Atrip_Color_Brand_Spec_v1.md`（文件內版本 v1.1）。

## 1. 字體與文字層級

中文、英文與數字統一使用 Noto Sans TC，備援順序如下：

```css
font-family: "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif;
```

載入字重 400、500、600、700；Logo 使用品牌圖檔，不以文字字型替代。內文字距為 0，英文不強制全大寫。

| 樣式名稱 | 字級 | 行高 | 字重 | 用途 |
|---|---:|---:|---:|---|
| type.display | 28px / 1.75rem | 40px / 2.5rem | 700 | 首頁主宣言，例如「下一站，想去哪裡？」 |
| type.h1 | 20px / 1.25rem | 30px / 1.875rem | 700 | 一般頁面主標題 |
| type.h2 | 16px / 1rem | 24px / 1.5rem | 600 | 區塊標題、卡片標題 |
| type.body | 14px / 0.875rem | 22px / 1.375rem | 400 | 一般內容與說明 |
| type.caption | 12px / 0.75rem | 18px / 1.125rem | 400 | 日期、天數、輔助資訊 |
| type.button | 16px / 1rem | 24px / 1.5rem | 600 | 主要與次要按鈕文字 |
| type.chip | 14px / 0.875rem | 20px / 1.25rem | 500 | 偏好標籤文字 |
| type.input | 16px / 1rem | 24px / 1.5rem | 400 | 輸入欄位、選單內容 |

H1／H2／Body／Caption 依工單字級；Display 是首頁主宣言的補充樣式。rem 換算以根字級 16px 為基準，前端不鎖死使用者的字級設定。

文字規則：

- 一般頁面以 H1 作主標題、H2 作區塊標題；首頁主標題可套用 Display 樣式，仍使用 h1 語意。
- 內文、說明及操作名稱允許換行；不以縮小字級來容納長文。
- 輔助文字最小採 Caption 12px。按鈕與輸入欄位不使用 Caption 樣式。
- 標題、主要文字使用 text.primary；輔助文字使用 text.secondary，不額外降低透明度。

## 2. 間距

以 4px 為基本單位。Figma 使用 px，前端間距可依同一比例轉為 rem。

| Token | 數值 | 主要用途 |
|---|---:|---|
| space.1 | 4px | 標題與次要資訊的小間距 |
| space.2 | 8px | 圖示與文字、標籤間距 |
| space.3 | 12px | 相鄰卡片、標題與內容 |
| space.4 | 16px | 卡片內距、表單欄位間距 |
| space.5 | 20px | 手機頁面左右內距 |
| space.6 | 24px | 主要內容與行動區之間 |
| space.8 | 32px | 不同內容區塊之間 |

## 3. 手機版面

- 設計檢核基準為 375px 寬，並檢查 320px、390px、430px 寬下的內容換行與點擊範圍。
- 頁面左右內距 20px；375px 畫面可用內容寬度為 335px。畫面小於 360px 時，左右內距改為 16px。
- 主要內容以單欄排列。標籤與卡片可在內容區內使用多欄，寬度不足時換行。
- 標籤列使用彈性換行、間距 8px，不固定所有標籤等寬。中文長標籤不截斷；超出可用寬度時在標籤內換行並增高。
- 雙欄卡片的間距為 12px；單卡最小寬度 152px，容器不足 316px 時切為單欄。文字放大後若內容無法容納，也需改為單欄。
- 區塊標題與內容間距 12px，區塊之間 32px；卡片內距 16px。
- 頁面隨內容自然增高，不使用固定內容高度裁切文字。一般內容不應產生水平捲動。
- 若使用固定底部導覽，內容底部需保留導覽實際高度及裝置安全區，避免遮住最後一個操作元件。導覽建議最小高度 64px，安全區另計。

## 4. 共用元件尺寸

| 元件 | 尺寸規則 | 內距／間距 |
|---|---|---|
| 主要／次要按鈕 | 最小高度 52px | 左右 20px、上下 12px；圖示與文字間距 8px |
| 偏好 Chip／Pill | 最小高度 44px | 左右 12px、上下 10px；圖示與文字間距 8px |
| 輸入欄位／選單 | 最小高度 48px | 左右 12px、上下 12px |
| 純圖示按鈕 | 最小點擊範圍 44 × 44px | 圖示置中 |
| 一般資訊標籤 | 依內容自然增高，無操作功能 | 左右 8px、上下 4px；字體採 Caption |

所有高度均包含內距與邊框，採 border-box；內容換行時允許元件增高。偏好標籤採 44px，滿足工單手機點擊區至少 40px 的要求。

圖示採同一套線性圖示：Chip 18px、一般按鈕 20px、主要導覽 24px。圖示視覺尺寸與按鈕點擊範圍分開設定，純圖示按鈕須提供可讀名稱。

## 5. 圓角與邊框

| Token | 數值 | 用途 |
|---|---:|---|
| radius.sm | 8px | 一般資訊標籤 |
| radius.md | 12px | 輸入欄位、選單 |
| radius.lg | 16px | 提示區塊、小型容器 |
| radius.xl | 20px | 景點／旅程卡片 |
| radius.full | 9999px | 主要按鈕、Chip／Pill |

卡片圖片沿用外層卡片圓角裁切。一般邊框寬度 1px；Chip 預留 2px 透明邊框，選中後只改邊框顏色，避免版面跳動。選中狀態同時提供勾選標記。

## 6. 陰影

| Token | CSS 值 | 用途 |
|---|---|---|
| shadow.none | none | 一般頁面、預設卡片、按鈕與標籤 |
| shadow.soft | 0 2px 8px rgba(24, 43, 54, 0.06) | 已選 Chip 的輕微浮起效果 |
| shadow.popover | 0 8px 24px rgba(24, 43, 54, 0.12) | 浮層選單、對話框 |

以留白與細邊框區分一般卡片，不為每個區塊加入陰影。陰影不作為選取或焦點狀態的唯一提示。

## 7. 版面驗收條件

- 375px 寬下，標籤點擊高度至少 44px，文字與圖示無裁切。
- 320px 至 430px 寬下，長標題、標籤及卡片內容可換行，無重疊或非必要水平捲動。
- 文字放大至 200% 時，容器與按鈕可增高，主要操作仍可使用。
- 有底部導覽時，最後一個內容項目與操作按鈕不被遮住。
- 使用指定字型與備援字型時，內容均能完整顯示。
