## 1. 任務說明 (What to Build)
在行程主畫布中整合互動地圖視圖（Mapbox GL JS 或 Leaflet），依據當前選取之天數標記所有景點座標（Marker），繪製簡要路線軌跡。實作點擊景點卡片時地圖平滑滾動（`flyTo`）至該坐標點，並彈出客製化 Popup 資訊視窗。

---

## 2. 輸入與輸出資料規格 (Data Specification)

### 2.1 輸入規格
* 當前天數之 `activities[].coordinates` (`{ lat: number, lng: number }`)。
* 景點名稱與類別標籤。

### 2.2 輸出規格
* **地圖實例控制**：
  * 當切換天數時，地圖呼叫 `fitBounds` 自適應縮放至包含當日所有座標。
  * 當點擊卡片時，地圖呼叫 `map.flyTo({ center: [lng, lat], zoom: 15, duration: 1.2 })`。

---

## 3. 詳細執行步驟 (Step-by-Step Checklist)
- [ ] 安裝地圖套件（建議使用 Leaflet + React-Leaflet 或 Mapbox GL）。
- [ ] 實作視圖切換按鈕（「時間軸視圖」/「地圖視圖」/「半屏分割視圖」）。
- [ ] 依據各活動之 `coordinates` 在地圖動態標記帶有數字序號之 Custom Markers。
- [ ] 撰寫卡片與地圖聯動事件：卡片獲取焦點或點擊時，驅動地圖中心點轉移並展開 Popup。
- [ ] 針對空坐標或離群坐標實作防呆處理。

---

## 4. 驗收條件 (Acceptance Criteria)
- [ ] 當天所有景點之坐標皆能在地圖精準標記，無漂移破圖。
- [ ] 點選任一時間軸活動卡片，地圖在 1.5 秒內平滑飛躍至目標景點並展開名稱氣泡。
- [ ] 地圖在行動裝置上縮放、拖曳流暢，無記憶體洩漏現象。
