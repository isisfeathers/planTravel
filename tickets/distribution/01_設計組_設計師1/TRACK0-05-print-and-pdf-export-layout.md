## 1. 任務說明 (What to Build)
制定適合 A4 直式列印與電子閱讀的離線行程 PDF 視覺版型與 `@media print` CSS 排版規範，確保活動卡片在實體列印或轉為 PDF 檔案時不會發生分頁文字腰斬（斷頭）或雜訊干擾。

---

## 2. 輸入與輸出資料規格 (Data Specification)

### 2.1 輸入規格
* [Final SPEC/01-產品需求規格與使用者流程(PRD).md](../Final%20SPEC/01-產品需求規格與使用者流程(PRD).md) 離線 PDF 規格。
* `tickets/mocks/mock_itinerary.json` 完整行程內容。

### 2.2 輸出規格
* **A4 PDF 版型視覺規範**：
  * 頁首：Atrip Logo ＋ 行程標題 ＋ 目的地 ＋ 規劃總天數。
  * 每日分隔：清晰的 Day Header，標示日期與本日精華摘要。
  * 活動節點：簡潔線條、時間、景點、地址與交通指引。
  * 頁尾：頁碼（例如 `第 1 頁，共 4 頁`）。
* **CSS 列印樣式規範清單**：
  * 隱藏元素清單（所有導航列、底部按鈕、拖曳把手、分享浮水印）。
  * 分頁防斷行規則：`page-break-inside: avoid`、`break-inside: avoid`。

## 3. 詳細執行步驟 (Step-by-Step Checklist)
- [ ] 於 Figma 建立標準 A4 (210mm x 297mm) 畫布，設計兼具美觀與省墨的黑白/雙色列印排版。
- [ ] 制定 `@media print` 樣式屬性表：指定邊距 `margin: 15mm`、基底字級 10pt。
- [ ] 設計封面概要區塊與每日活動卡片佈局，規範防截斷屬性。
- [ ] 交付 CSS 列印規則與視覺範例給 Track 1 (前端開發組)。

## 4. 驗收條件 (Acceptance Criteria)
- [ ] A4 預覽在標準雙面列印與 PDF 檢視下無邊界裁切。
- [ ] 單張景點卡片絕不跨頁腰斬，換日自動啟動新分頁或具備乾淨頁首分隔。
- [ ] 列印狀態下完全隱藏所有網頁版互動按鈕與輸入框。
