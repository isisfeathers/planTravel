# 01 產品需求規格與使用者流程 (PRD & User Flow)

* **產品名稱**：Atrip（你的 AI 自由行規劃夥伴）
* **版本**：v2.0.0
* **目標平台**：LINE LIFF (Mobile-First RWD Web App)

---

## 1. 產品目標與核心價值主張 (Value Proposition)

1. **極速規劃（15 秒完成需求設定）**：
   * 透過**雙層標籤精靈**，預設點亮「🏆 平台推薦經典遊」套版，用戶可 0 點擊 1 秒內直接發動 AI 規劃，徹底消除文字填答的負擔。
2. **高真實度行程（告別空洞 AI 推薦）**：
   * 結合動態提示詞技術，行程自帶真實地圖經緯度座標、捷運行駛路線代碼與出入口、連住基地 (Basecamp) 或分區換宿的行李寄存節點。
3. **無縫非同步體驗（不卡頓、不中斷）**：
   * 結合 Supabase Realtime 與 LINE 官方帳號 Flex Message 雙軌通知，跳出頁面也能精準接收完成提醒。
4. **社群擴散與離線隨身行**：
   * 專屬外連分享免登入即可瀏覽去識別化行程；旅伴一鍵「複製到我的行程 (Fork)」即可接手二次客製，支援高品質離線 PDF 匯出。

## 3. 完整使用者故事清單 (User Stories)

### 3.1 登入、首頁與多行程管理
1. 作為一名 LINE 使用者，我想要在點擊官方帳號 Rich Menu 後免密碼自動登入 Web App，以便我無需記憶密碼即可立即開始使用。
2. 作為一名規劃多趟旅行的用戶，我想要在進入系統後看到我的所有行程列表（包含規劃中、即將出發與已封存），以便我能清楚掌握不同目的地的旅程。
3. 作為一名用戶，我想要在行程儀表板上看到醒目的「＋ 規劃新旅程」主按鈕，以便我能隨時開啟全新的旅行規劃。
4. 作為一名擁有多個行程的用戶，我想要將其中一個行程標記為「★ 當前關注行程」，以便我在 LINE 聊天室與 Chatbot 對話時，系統能自動以該行程作為上下文。
5. 作為一名用戶，我想要在行程卡片選單中執行「封存」或「軟刪除」，以便我清理不再需要的行程，同時享有 30 天內防誤觸復原保護。

### 3.2 雙層標籤精靈與偏好配置
6. 作為一名不想花時間打字的懶人用戶，我想要在新增行程時看到預先點亮的「🏆 平台推薦經典遊」套版，以便我可以直接 0 點擊點選「開始規劃」立即生成行程。
7. 作為一名購物愛好者，我想要點選「🛍️ 都會潮流血拚狂」套版，以便系統自動幫我帶入連住市區商圈、大眾運輸與商圈標籤。
8. 作為一名體育迷，我想要點選「⚾ 熱血運動賽事遊」套版並填寫特定比賽日期/時間，以便 AI 將該場賽事作為當日不可變更的重點時間錨點。
9. 作為一名重視住宿體驗的用戶，我想要選擇「連住同一間」或「隨景點分區換宿」，以便 AI 根據我的行李移動需求妥善安排動線（連住以首日飯店為基地；換宿自動插入行李寄放與 Check-in 節點）。
10. 作為一名精打細算的背包客，我想要選擇「大眾運輸優先」，以便 AI 在行程中精準標註地圖捷運線路代碼、建議出入口與乘車時間。
11. 作為一名自駕遊客，我想要選擇「租車自駕/包車」，以便 AI 提示景點間的行車距離、車程與周邊停車便利度。
12. 作為一名常客，我想要系統自動記住我過去常用的個人偏好，以便我下次規劃新行程時無需重新設定。

### 3.3 非同步任務與機票服務
13. 作為一名送出規劃請求的用戶，我想要在等待頁面看到動態載入動畫與旅遊實用 Tips，以便我在等待 AI 生成的 15~30 秒內不感到無聊。
14. 作為一名臨時關閉 LIFF 畫面的用戶，我想要在行程生成完畢後在 LINE 聊天室收到精美的 Flex Message 通知，以便我能點擊一鍵返回查看我的專屬行程。
15. 作為一名停留在畫面的用戶，我想要行程一完成時頁面透過 Supabase Realtime 自動更新並呈現行程，無需我手動刷新頁面。
16. 作為一名需要訂機票的用戶，我想要在行程頂部看到合法授權 API 查詢之即時機票比價卡片，並能點擊授權 Deep Link 直接跳轉至航空公司或 OTA 結帳頁。
17. 作為一名系統維運者，我想要限制單一用戶每日最多生成 3 次、活躍行程上限 5 個，以便防止 API 配額被惡意刷爆並保障伺服器資源。

### 3.4 主畫布互動與行李清單
18. 作為一名檢視行程的用戶，我想要按天數 Tab 切換查看每天的時間軸卡片，以便我清晰閱讀每天從早到晚的活動排程。
19. 作為一名想要調整行程的用戶，我想要透過滑鼠或手指長按拖曳景點卡片改變先後順序，以便我依照個人喜好微調景點。
20. 作為一名完成景點拖拉重排的用戶，我想要系統自動將整包 JSONB 更新寫回資料庫，以便我的修改隨時自動儲存不遺失。
21. 作為一名查看地圖的用戶，我想要在點擊任一景點卡片時地圖平滑滾動至該座標並開啟氣泡資訊，以便我清楚掌握地理相對位置。
22. 作為一名旅人，我想要在景點之間看到具體的交通方式膠囊標籤（含轉乘方式、路線名稱與耗時），以便我清楚知道如何前往下一站。
23. 作為一名準備行李的旅客，我想要切換至「行李清單」分頁，查看 AI 根據目的地與氣候推薦的必備物品，並能打勾完成確認。

### 3.5 分享、社群複製 (Fork) 與離線匯出
24. 作為一名想要與朋友分享行程的用戶，我想要一鍵複製專屬外連分享網址，以便任何人在未登入狀態下也能直接於瀏覽器唯讀瀏覽去識別化的行程內容。
25. 作為一名收到朋友行程分享的訪客，我想要點擊「複製到我的行程 (Fork)」按鈕，以便將該行程原封不動複製到我的帳號下作為個人副本自由編輯。
26. 作為一名需要離線查閱行程的出國旅客，我想要一鍵匯出高品質 PDF，以便我在飛機上或無網路環境下隨時查看行程。
27. 作為一名使用 LINE 內建瀏覽器的用戶，我想要點擊「傳送 PDF 到 LINE 聊天室」，以便克服 LINE 阻擋瀏覽器下載檔案的問題，直接在對話框取得 PDF 檔案。

## 4. 逐畫面核心 UI/UX 設計規格 (Screen Specifications)

### 畫面 1：我的行程儀表板 (Dashboard / List View)
* **視覺主軸**：頂部品牌 Header（Atrip Logo ＋ 標語「你的 AI 自由行規劃夥伴」），背景為雲白灰 (`#F8FAFC`)。
* **分頁籤 (Tabs)**：
  * **活躍中行程 (Active & Upcoming)**：顯示各行程的封面圖、目的地標題、日期區間、倒數天數、進度狀態（規劃中、已就緒）與標記「★ 當前關注」徽章。
  * **歷史旅程 (Archived)**：已過期或手動封存之行程。
* **主要按鈕**：
  * **頂部浮動主行動鈕**：`旅行藍` (`#347FA3`) 底色，白色文字「＋ 規劃新旅程」，點擊開啟標籤精靈。
  * **卡片右上選單 (`...`)**：包含「設為當前關注」、「修改標題」、「封存」與「移至垃圾桶（軟刪除）」。

### 畫面 2：雙層式標籤精靈 (Quick-Choice Chip Selector)
* **第 1 層：一鍵懶人套版膠囊 (Preset Bundles - 頂部橫向滾動)**：
  * `🏆 平台推薦經典遊`（預設已選中點亮）：自動設定「依推薦連住同一間」＋「大眾運輸優先」＋「慢活 2~3 景點」＋「#在地老饕 #經典必訪」。
  * `🛍️ 都會潮流血拚狂`：自動切換「連住市區商圈」＋「大眾運輸」＋「充實滿檔」＋「#百貨商場 #特色潮流小店 #下午茶咖啡」。
  * `⚾ 熱血運動賽事遊`：自動切換「交通樞紐住宿」＋「大眾運輸」＋「適中節奏」＋「#運動賽事/球場 #周邊應援旗艦店」。
* **第 2 層：自選微調按鈕矩陣 (下方展開區)**：
  * **目的地捷徑**：熱門城市 Chip（`東京`、`大阪`、`京都`、`首爾`、`曼谷`、`福岡`），支援手動搜尋。
  * **住宿策略**：單選膠囊（`連住同一間 (以第 1 晚為基地)` vs `隨景點換宿 (自動安排行李寄放)`）。
  * **交通方式**：單選膠囊（`大眾運輸優先` vs `租車自駕/包車`）。
  * **主題標籤**：可多選 Pills（`#在地老饕` `#米其林摘星` `#文青古蹟` `#購物商圈` `#運動賽事` `#自然秘境`）。
  * **運動賽事時間錨點備註欄**：若勾選 `#運動賽事` 自動展開輸入框，填入如 `週五晚間 18:00 東京巨蛋`，作為不可撼動之錨點。
* **底部主行動鈕**：`暖日橘` (`#F97316`)「一鍵開始 AI 規劃」，懶人用戶直接點擊即可秒發動。

### 畫面 3：動態等待畫布 (Generating Screen)
* **視覺呈現**：非單調轉圈，呈現飛機航線微動畫與骨架屏（Skeleton Loading）。
* **互動內容**：輪播展示目的地旅遊實用 Tips（如「日本地鐵搭乘禮儀」、「出入境電子申報教學」）。
* **狀態監聽**：前端自動開啟 Supabase Realtime Channel，一旦監聽到該筆 `itinerary_jobs` 狀態轉為 `completed`，平滑漸變導航至主畫布。

### 畫面 4：動態行程主畫布 (Interactive Itinerary Canvas)
* **頂部工具列**：行程標題、天數切換 Tab (`Day 1`, `Day 2` ... `行李清單`、`機票推薦`)、一鍵分享、匯出 PDF。
* **視圖切換 (雙模)**：
  * **時間軸視圖**：卡片顯示時段、景點名稱、分類標籤、預估時間、交通轉乘提示膠囊（如 `🚇 東京地鐵銀座線 (澀谷方面) 乘車 8 分，A3 出口步行 3 分`）。
  * **地圖視圖**：整合 Mapbox / Leaflet，以 Day 顏色標記座標點，點擊景點卡片平滑平移（FlyTo）至該座標並開啟 Popup。
* **互動編輯**：長按/拖曳景點卡片改變次序，觸發防抖 800ms 整包覆蓋更新至 Supabase。

### 畫面 5：行李打包清單 (Packing List Tab)
* **資料來源**：LLM 根據目的地、出發月份氣候與天數自動生成。
* **分類模組**：
  * **重要證件與金流**：護照、機票憑證、外幣、信用卡、SIM/eSIM。
  * **衣物與隨身裝備**：依季節推薦保暖/防曬衣物、便攜雨具、舒適步行鞋。
  * **3C 與生活必備**：行動電源、轉接插頭、個人常備藥品。
* **互動**：前端 Checkbox 勾選狀態即時寫入 JSONB，方便行前清點。

### 畫面 6：去識別化外連分享與複製 (Fork to My Itineraries)
* **分享網址**：`https://atrip.app/share/[share_token]`。
* **去識別化保護**：自動遮蔽建立者姓名、頭像、花費預算數字與偏好快照，僅開放景點時間軸、地圖與交通指引。
* **複製副本 (Fork)**：頂部醒目橫幅「喜歡這個行程？一鍵複製到我的行程」，訪客登入後自動於其帳號下產生獨立副本，立即開啟編輯。
